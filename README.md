# AI R-TYPE

R-Typeライクな横スクロールシューティングゲーム。ブラウザで動作し、PC・スマホ・ゲームパッドに対応。

**[▶ Play Online](https://unkei.github.io/ai-rtype/)**

## 操作方法

| 操作 | キーボード | ゲームパッド | タッチ |
|------|-----------|-------------|--------|
| 移動 | 矢印キー / WASD | 左スティック / 十字キー | 左側バーチャルスティック |
| ショット | Z / Space | A ボタン | 右側 FIRE ボタン |
| チャージショット | Z / Space 長押し→離す | A 長押し→離す | FIRE 長押し→離す |
| ポーズ | Esc / P | Start | — |

## ゲームの特徴

- **チャージショット**: ボタンを押し続けてチャージ、離すと強力なビームを発射(R-Typeの醍醐味)
- **3種類の敵**: 直進型(Type A)・サイン波型(Type B・自機狙い弾あり)・編隊型(Type C)
- **10ループのウェーブ**: 難度が上がりながら繰り返すステージ1
- **ハイスコア**: ブラウザに記録・ゲームオーバー時に表示
- **爆発エフェクト & SE**: Web Audio APIによるサウンド、パーティクルエフェクト
- **レスポンシブ**: 16:9の内部解像度960×540、どの画面サイズでも全画面表示

## 開発

純粋なHTML5 Canvas + Vanilla JS。ビルド不要。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

開発の継続方法・ブランチ戦略は [CLAUDE.md](./CLAUDE.md) と [docs/TASKS.md](./docs/TASKS.md) を参照。
